# Fly Core v1 冻结实验规范

## 研究问题

在固定且公开的行情感知与动作解释接口下，MaleCNS 连接组产生的方向信号是否具有可重复、优于对照组的市场表现？

项目不声称果蝇理解金融市场。人工只定义不可避免的感知和动作接口；果蝇原始轨道之后的过滤与风控必须独立计量。

## 主指标与对照

- fly_raw：固定行情映射、MaleCNS 动力学和固定阈值解码的直接结果，是唯一主实验指标。
- fly_filtered：EMA、自适应阈值、迟滞、预热和信号冷却结果，只作为人工过滤对照。
- risk_executable：人工过滤结果再通过账户与市场风控，只作为现实可执行性对照。
- buy_and_hold：买入持有基准。
- random_same_frequency：与 fly_raw 相同交易频率的固定种子随机基准。
- disconnected_connectome：连接断开后方向输出期望值为零的无方向暴露基准；当前是期望值对照，不是随机神经动力学重跑。

## 冻结规则

- 实验编号为 fly-core-v1。
- schema 8 事件包含完整实验规范及其 SHA-256 指纹。
- 回放默认拒绝旧 schema、其他实验编号或指纹不一致的事件。
- 修改刺激映射、神经参数、原始阈值或主指标定义时，必须创建新的实验编号。
- 不允许根据 fly-core-v1 的收益回头调整其参数，再把调整后的结果并入同一实验。
- 风控只决定 risk_executable，不得覆盖 fly_raw 历史。

## 解释边界

fly_raw 仍包含人为规定的视觉编码和动作解码；它代表“固定人工接口下的果蝇连接组表现”，不代表自然果蝇具有交易能力。
