# Fly Core v1 冻结实验规范

## 研究问题

在固定且公开的行情感知与动作解释接口下，MaleCNS 连接组产生的方向信号是否具有可重复、优于对照组的市场表现？

项目不声称果蝇理解金融市场。人工只定义不可避免的感知和动作接口；果蝇原始轨道之后的过滤与风控必须独立计量。

## 主指标与对照

- fly_raw：固定行情映射、MaleCNS 动力学和固定阈值解码的直接结果，是唯一主实验指标。
- fly_filtered：EMA、自适应阈值、迟滞、预热和信号冷却结果，只作为人工过滤对照。
- risk_executable：人工过滤结果再通过账户与市场风控，只作为现实可执行性对照。
- buy_and_hold：买入持有基准。
- random_same_frequency：与 fly_raw 相同交易频率的固定种子随机基准。
- disconnected_connectome：连接断开后方向输出期望值为零的无方向暴露基准；当前是期望值对照，不是随机神经动力学重跑。

## 冻结规则

- 实验编号为 fly-core-v1。
- schema 8 事件包含完整实验规范及其 SHA-256 指纹。
- 回放默认拒绝旧 schema、其他实验编号或指纹不一致的事件。
- 修改刺激映射、神经参数、原始阈值或主指标定义时，必须创建新的实验编号。
- 不允许根据 fly-core-v1 的收益回头调整其参数，再把调整后的结果并入同一实验。
- 风控只决定 risk_executable，不得覆盖 fly_raw 历史。

## 解释边界

fly_raw 仍包含人为规定的视觉编码和动作解码；它代表“固定人工接口下的果蝇连接组表现”，不代表自然果蝇具有交易能力。


## 本地资金池运行规则（local-pool-v1）

原始信号接口和 `fly-core-v1` 指纹不变。新增运行编号 `run_id` 与独立模拟规则版本 `local-pool-v1`，用于区分信号实验定义和资金池记账规则。不同运行的结果不自动拼接。

- 每次实验的美元、港元初始现金分别为 1,000,000，按市场共享；重置神经、过滤器及提案状态。
- 风控通过的提案按数量模拟成交一次；费用 3bp、滑点 5bp，原有单股全仓归一化收益仅作独立对照。
- 准备完成后双市场共享起点，按经过时间计时，暂停仍计时。无行情也必须到期停止。
- 结束时禁止新决策与成交，持仓按最后有效行情估值，不模拟强制平仓；记录估值时间、过期标记、无行情及预热未完成情况。
- 结果、成交账本及事件保存于 `logs/runs/<run_id>/`。网页保持可访问，允许下载结果或开始新实验。
- 单市场出错不终止另一市场，报告明确记录失败；历史回放不作为共享资金池结算报告。

本地控制接口：`POST /api/experiment/start` 接收 `us_symbols`、`hk_symbols`（文本或列表）和正数 `duration_s`；`POST /api/experiment/stop` 提前结束；`POST /api/pause` 接收布尔值 `paused`；`GET /api/state` 返回状态与账户；`GET /api/experiment/report` 返回最终 JSON 报告。无效参数返回 400，状态冲突或报告未就绪返回 409。网页不支持无限时长，命令行显式 `--auto-start --duration 0` 可无限运行。


## 独立轨道资金池（track-pools-v2）

当前模拟规则版本为 `track-pools-v2`，不覆盖历史 `local-pool-v1` 报告；原始神经信号实验指纹仍不变。

五条轨道分别拥有 USD 1,000,000 和 HKD 1,000,000。原始、过滤、买入持有轨道按选股数等分预算，BUY 空仓建仓、SELL 清仓，以整股/整手及费用后的可用现金限制数量；风控轨道保持原有数量和限制。断开连接组为现金对照。成本及盈亏直接来自各轨道的独立账本，收益率分母为该轨道、该币种的初始一百万。

`/api/state` 和最终报告新增 `track_accounts[market][track]`；其中 `symbol_records` 保留清仓股票的累计买卖数量、平均成交价、当前含费成本、已实现和未实现盈亏。报告 `track_trades[market][track]` 保存全部成交；JSONL 成交包含 `track`。旧 `accounts` 与 `trades` 字段仅为风控轨道的兼容别名，不能用于代表五轨道总资金。旧离线回放仍按归一化单股信号估算，不是新版轨道资金池结算。
