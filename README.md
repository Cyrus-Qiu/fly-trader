# Fly Trader：果蝇 MaleCNS 双市场实验

Fly Trader 是一个在 Windows 上运行的本地模拟研究项目。它把美股和港股行情编码为果蝇 MaleCNS 连接组的视觉刺激，让简化的脉冲神经网络持续运行，再把神经活动解释为 `BUY`、`HOLD`、`SELL` 研究信号，并在本地页面实时比较不同实验轨道的假想收益。

项目当前接入：

- 长桥 OpenAPI：统一港股与美股行情。美股支持盘前、常规、盘后、夜盘；港股仅按交易日历的交易时段模拟。
- 优先连接中国内地接入点，失败后尝试国际接入点；开启美股夜盘。权限或网络不足时明确提示，不伪造实时行情。
- 本地模拟资金池：每条实验轨道各自拥有 100 万美元和 100 万港元，不再读取任何券商账户余额或持仓。

项目不会提交、修改或撤销订单。页面中的“买入”“卖出”“风控可执行”和“订单提案”都只是研究记录或假想执行结果，不是券商账户里的真实交易，也不是投资建议。

当前冻结实验是 `fly-core-v1`，统一事件格式是 schema 8。详细冻结规则见 [docs/experiment-protocol.md](docs/experiment-protocol.md)。

## 默认运行内容

双击根目录的 `启动 Fly Trader.cmd`，等价于在项目根目录执行：

```powershell
.\.venv\Scripts\fly-trader.exe --source both
```

启动后先打开配置页，不自动订阅固定股票。在页面分别填写美股、港股代码（逗号或空白分隔，允许只选一个市场），填写持续时长，再点击“开始实验”。默认时长为 60 分钟。

模型和必要资料准备好后开始倒计时；等待行情和暂停期间仍计时。到期停止行情和神经计算，按最后有效行情估值，不强制平仓。网页继续提供结果和 JSON 报告下载，也可以开始新实验。每次实验重新初始化神经状态、预热、资金及持仓。

程序会加载一份共享的 MaleCNS 连接矩阵，但为每个标的建立完全独立的膜电位、放电、随机数、行情刺激、信号过滤器和收益账户。不同股票的行情不会混入同一个神经状态。

## 系统是怎么工作的

整体处理链如下：

```text
行情源 → 标准化快照与去重 → 六路视觉刺激 → MaleCNS LIF 神经动力学
     → 原始神经读出 → 人工过滤对照 → 只读风控对照
     → JSONL 日志 + 状态检查点 + 本地仪表盘 + 离线回放
```

### 1. 接收并标准化行情

所有行情先转换为统一的 `MarketSnapshot`，主要字段包括标的、提供方时间戳、前参考价、开高低收、成交量、停牌状态、行情源和事件类型。

去重键是 `(symbol, feed, market_time_ms)`：相同时间戳不会处理两次，晚到且早于最新时间戳的数据也会被丢弃。这样能避免 WebSocket 重发或轮询重复造成神经网络被同一行情反复刺激。

各时段报价口径：

- 美股按美东时间自动选择：盘前 04:00–09:30、常规 09:30–16:00、盘后 16:00–20:00、夜盘 20:00–次日 04:00，并处理夏令时、周末和休市日。
- 长桥盘前/盘后/夜盘使用 `pre_market_quote`、`post_market_quote`、`overnight_quote`，不能拿常规收盘价代替。缺少当前时段报价时继续等待。
- 开启 `enable_overnight=True`，使用实时报价推送及固定周期轮询；某只股票持续推送不会阻止其他股票的轮询更新。
- 保留原始行情时间；SDK 的无时区时间按机器本地时间转换，不直接标成 UTC。报价过期、停牌或当前市场休市时，各资金轨道均暂停新成交。
- 港股没有盘前/盘后/夜盘分支，午休、收市和休市日不会继续用旧报价模拟买卖。

### 2. 用独立时钟驱动神经网络

模型不会“来一条行情才运行一次”。每个标的都有持续的神经时钟：港股固定 50Hz；美股不超过两个标的时为 50Hz，三个及以上标的时默认降到 25Hz，也可以通过 `--neural-hz` 覆盖。

行情到达时只更新最新刺激，不堆积过时刺激。最新报价超过 2 秒后，刺激强度在接下来的 3 秒内线性衰减；超过 5 秒后刺激归零，并强制人工过滤轨道进入 `HOLD`。

### 3. 把行情映射成六路视觉刺激

MaleCNS 视觉受体被顺序划分成六个连续区域，每个区域接收一种固定特征：

| 区域 | 输入特征 | 归一化方式 |
|---|---|---|
| 0 | `close / reference_price` 的对数收益 | 2% 映射为 ±1，再映射到 0..1 |
| 1 | 区域 0 的相反方向 | 同上 |
| 2 | `close / open` 的对数收益 | 同上 |
| 3 | 区域 2 的相反方向 | 同上 |
| 4 | 收盘价在本次高低区间中的位置 | -1..1 映射到 0..1 |
| 5 | 本次振幅与相邻快照成交量对数变化 | 截断到 0..1 |

停牌时所有外部视觉刺激归零。这个映射是人为定义的实验接口，不是生物学结论。

### 4. 运行 MaleCNS LIF 动力学

项目加载 `data/malecns` 中的稀疏连接矩阵和神经元分组，运行简化的 leaky integrate-and-fire 模型。`fly-core-v1` 冻结参数为：

| 参数 | 数值 |
|---|---:|
| 内部时间步长 `dt` | 20ms |
| 膜时间常数 | 100ms |
| 放电阈值 | 1.0 |
| 突触增益 | 1.5 |
| 恒定电流 | 0.180 |
| 背景活动 | 1.2Hz Bernoulli |
| 背景活动幅值 | 0.22 |
| 视觉增益 | 0.62 |

神经活动按约 260ms 的窗口读出。原连接组中的右转池 `DNa02/DNg13` 作为 BUY 方向证据，左转池作为 SELL 方向证据：

```text
score = (buy_rate - sell_rate) × 1100
```

原始分数 `>= 8` 输出 BUY，`<= -8` 输出 SELL，其余输出 HOLD。`DNg100` 和 `DNp01/DNp10` 只记录为唤醒度相关活动，不直接决定方向。

### 5. 同时保留三条实验轨道

三条轨道写入同一条 schema 8 事件，但互不覆盖：

| 轨道 | 页面名称 | 含义 |
|---|---|---|
| `fly_raw` | 果蝇原始 | 固定行情编码、神经动力学和 ±8 解码器的直接输出；这是主科学指标 |
| `fly_filtered` | 人工过滤 | 对原始分数做平滑、预热、自适应阈值、迟滞和冷却；只作为人工干预对照 |
| `risk_executable` | 风控可执行 | 人工过滤信号再经过市场和账户风控；通过时按提案数量在本地资金池模拟成交 |

人工过滤先计算最近 1 秒原始分数均值，再使用 0.35 秒半衰期 EMA。每只股票独立预热 5 分钟，并至少积累美股 100 个、港股 30 个有效样本。进入阈值取最近 30 分钟绝对平滑分数的第 95 百分位，并限制在 2 到 20；退出阈值是进入阈值的 40%。状态改变后有 1 秒冷却。

这样设计的目的不是让人工过滤“冒充果蝇表现”，而是同时回答两个问题：果蝇原始输出本身怎样，以及现实世界的平滑和约束会怎样改变结果。

### 6. 生成只读风控提案

`risk_executable` 会检查：

- 标的是否在本次实验配置中；港股每手股数从长桥行情静态资料获取，缺失则阻止模拟成交。
- 人工过滤信号是否稳定持续 3 秒。
- 行情是否新鲜；美股是否处于盘前/常规/盘后/夜盘开放时段；港股是否处于常规连续交易时段。
- 是否为受支持的交易日；内置日历覆盖 2026–2027，超出范围时失败关闭。
- 本地资金池是否可用。
- 当日亏损是否达到 2% 熔断线。
- 是否只做多、是否有足够现金。
- 单标的仓位是否低于 10%，总仓位是否低于 70%。
- 距离上次提案是否已经超过 5 分钟。

通过检查后生成 `ready` 提案并记录一次本地模拟成交。美股每次 1 股，港股每次 1 手，卖出不超过持仓。手续费 3bp、滑点 5bp 都计入资金和仓位校验。同市场按配置顺序处理，后续股票读取成交后的账户。美元、港元分别记账，不兑换或混合计算收益。日初净值在当地交易日期变更时，以前一估值重置。

`order_submission_enabled` 始终为 `false`，代码不创建券商交易客户端，也没有提交订单调用路径。单市场和双市场均使用本地资金池。

### 7. 按独立资金计算实验收益

`fly_raw`（果蝇原始）、`fly_filtered`（人工过滤）、`risk_executable`（风控可执行）、`buy_and_hold`（买入持有）和 `disconnected_connectome`（现金对照）各自分配 100 万美元和 100 万港元，轨道之间互不借用资金。

原始、过滤与买入持有轨道将同币种的一百万按本次股票数等分。空仓收到 BUY 时，用该股票可用预算尽量买入整股/整手；SELL 时清仓，收益保留在该股票预算内，重复 BUY 不加仓。风控轨道继续使用原有提案数量和仓位限制。港股每手资料缺失时，各轨道均不模拟该股票成交。断开连接组保持现金，不运行额外的断连神经网络。

收益率统一按 `(现金 + 持仓市值 - 1,000,000) / 1,000,000` 计算。默认手续费 3bp 和滑点 5bp 已扣除；持仓成本采用含买入费用的加权平均成本。平均买入/卖出价不含费用，清仓后持仓成本价为空，但累计买入股数、卖出股数、平均成交价及已实现盈亏保留。

页面按市场展示各轨道的总资产、净收益、收益率、回撤、累计买卖股数及成交次数；点击轨道行或切换下拉框，可查看该轨道的现金、持仓、成本和逐股盈亏。到期报告与页面使用同一份账本。

## 安装与准备

### 环境要求

- Windows 10/11。
- Python 3.12 或更高版本。
- 可访问长桥及 GitHub 的网络。
- MaleCNS 原始数据需要约 1.1GB 下载空间，生成的缓存保存在本地 `data/`。

### 创建虚拟环境并安装

在仓库根目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
```

`requirements-lock.txt` 保存本项目验证过的精确版本；需要完全复现环境时可使用：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe -m pip install -e . --no-deps
```

### 准备 MaleCNS 缓存

连接组缓存格式和准备工具来自公开的 `ornata/fly` 项目。首次安装时执行：

```powershell
git clone https://github.com/ornata/fly.git _reference/ornata-fly
$env:PYTHONPATH = "_reference/ornata-fly"
.\.venv\Scripts\python.exe -m fly64.data --prepare --cache data/malecns
```

成功后 `data/malecns` 应包含 `model.npz`、`weights.npz` 和 `manifest.json`。`data/` 与 `_reference/` 都被 Git 忽略，不会上传到仓库。

### 配置凭据

复制 `.env.example` 为 `.env`，填写自己的凭据：

```dotenv
LONGBRIDGE_APP_KEY=你的_长桥_App_Key
LONGBRIDGE_APP_SECRET=你的_长桥_App_Secret
LONGBRIDGE_ACCESS_TOKEN=你的_长桥_Access_Token
```

程序启动时会读取项目根目录的 `.env`，并用它覆盖当前 PowerShell 中可能残留的同名变量。`.env` 已被 Git 忽略；不要把真实密钥写入 `.env.example`、README、日志或其他受版本控制的文件。

## 启动方式

### 默认网页配置模式

双击 `启动 Fly Trader.cmd`，或者执行：

```powershell
.\.venv\Scripts\fly-trader.exe --source both
```

### 只运行美股行情

`iex` 参数保留为旧版“仅美股”别名，实际使用长桥全时段行情：

```powershell
.\.venv\Scripts\fly-trader.exe --auto-start --source iex --symbols NVDA AAPL --duration 3600
```

页面保留美股最多 30 个标的限制，防止过多独立神经状态占用资源。

### 只运行港股行情

港股代码使用 `ticker.HK` 格式；纯数字会自动标准化，例如 `00700` 会变成 `700.HK`：

```powershell
.\.venv\Scripts\fly-trader.exe --auto-start --source longbridge --symbols 700.HK 9988.HK --duration 3600
```

### 常用参数

| 参数 | 作用 | 默认值 |
|---|---|---|
| `--source` | `both`、`iex`、`longbridge` 或 `replay` | `both` |
| `--symbols` | 自动开始时的美股标的；longbridge 模式表示港股标的 | 空 |
| `--hk-symbols` | 自动开始时双市场模式的港股标的 | 空 |
| `--duration 60` | 自动开始时的秒数；显式 0 表示直到手动结束 | `3600` |
| `--auto-start` | 使用命令行股票和时长直接开始；否则进入网页配置页 | 关闭 |
| `--dashboard-port 8790` | 修改本地仪表盘端口 | `8787` |
| `--no-browser` | 启动服务但不自动打开浏览器 | 关闭 |
| `--poll-seconds 2` | 长桥美股/港股快照轮询间隔，推送同时保持 | `2` |
| `--neural-hz 50` | 覆盖美股神经时钟频率 | 自动 |
| `--seed 64` | 神经随机数及回放基准种子 | `64` |
| `--log PATH` | 使用该路径的父目录存放 `runs/<run_id>/` | `logs/signals.jsonl` |

页面默认地址是 `http://127.0.0.1:8787/`，只绑定本机。

## 仪表盘内容

本地页面提供：

- 港股/美股标签和当前标的选择。
- 最新价格、行情来源、报价年龄和刺激衰减比例。
- 原始动作、稳定动作、原始分数、平滑分数、动态阈值和预热进度。
- 神经活动与价格滚动曲线。
- 五条独立资金轨道的资产、收益率、最大回撤、累计买卖股数与逐股成本/盈亏。
- 订单提案状态及逐项风控结果。
- 当前市场本地资金池的现金、资产、持仓和已实现/未实现盈亏。
- 接收、接纳、重复、队列丢弃和计算延迟等运行健康指标。
- 股票与时长配置、倒计时、暂停/继续、提前结束、结果展示和报告下载。

页面没有下单按钮，不展示 API 密钥，也不会向公网监听。

## 日志、状态与数据保存在哪里

每次实验分配独立运行编号；各市场分别写入日志：

| 内容 | 默认位置 |
|---|---|
| 美股 schema 8 事件 | `logs/runs/<run_id>/signals-us.jsonl` |
| 港股 schema 8 事件 | `logs/runs/<run_id>/signals-hk.jsonl` |
| 运行状态索引 | `logs/runs/<run_id>/signals-us.state.json`、`signals-hk.state.json` |
| 每个标的的神经状态 | 对应 `.state` 目录内的 NPZ 文件 |
| 模拟成交账本 | `logs/runs/<run_id>/trades-us.jsonl`、`trades-hk.jsonl` |
| 最终报告 | `logs/runs/<run_id>/report.json` |
| MaleCNS 模型缓存 | `data/malecns/` |
| 本地密钥 | `.env` |

每条合格行情都会写入完整事件；当行情未更新但三条轨道发生动作变化时，会额外写入较小的 `neural_transition` 事件。事件包含行情、六路刺激、神经读出、三条轨道、风控提案、实验编号、规范指纹、行情新鲜度和运行健康指标。

单个 JSONL 文件达到 100MB 后自动轮转，最多保留 48 份备份。异常退出留下的不完整尾行会在下次启动时修复。每 30 秒及正常退出时保存神经膜电位、放电、随机数、过滤器、自适应基线和风控冷却；这些检查点用于诊断；新实验不会恢复旧状态。事件包含 `run_id` 和 `simulation_version=track-pools-v2`。

`.env`、`data/`、`logs/`、`_reference/`、`.venv/` 和生成的 `*.egg-info/` 都被 Git 忽略。

## 离线回放与评估

对一个或多个历史日志运行：

```powershell
.\.venv\Scripts\fly-trader.exe --source replay `
  --replay-log logs\runs\RUN_ID\signals-us.jsonl logs\runs\RUN_ID\signals-hk.jsonl `
  --report logs\replay-report.json
```

将上例的 `RUN_ID` 替换为实际运行目录。该回放仍是单股信号对照，不重建共享资金池；独立轨道资金池结果以本次报告的 `track_accounts`、`track_trades` 和成交账本为准。

回放按标的分别评估 `fly_raw`、`fly_filtered` 和 `risk_executable`，并加入买入持有、固定种子随机同频和断开连接组基准。报告包含收益、最大回撤、交易次数、完整回合、胜率、换手率、暴露比例和数据缺口。

默认只接纳实验编号和指纹匹配的 `fly-core-v1` schema 8 事件，避免不同规则的数据混在一起。只有显式添加 `--include-legacy` 才读取旧格式事件。手续费与滑点默认分别为 3bp 和 5bp，可用 `--fee-bps`、`--slippage-bps` 修改。

## 研究边界与已知限制

- `fly_raw` 仍包含人为规定的感知和动作映射；它表示“固定人工接口下的连接组表现”，不表示自然果蝇理解市场。
- 长桥 OpenAPI 行情权限独立于 App；仍受订阅权限、标的活跃程度及网络影响，全时段支持不代表休市时也有新成交。
- 程序保留行情时间并阻止过期报价成交；不会把延迟快照伪装成实时价格。
- 页面收益是假想的全仓单标的模型，只用于横向比较，不模拟订单簿深度、部分成交、税费、汇率变化和真实券商规则。
- 内置休市日历只覆盖 2026–2027；范围外的提案会被拒绝。
- 当前项目适合做可重复实验和对照分析，不适合连接真实资金。
